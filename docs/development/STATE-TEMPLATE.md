# STATE.md 模板（用于复杂任务）

当开发复杂功能（涉及 > 3 个文件）时，使用此模板追踪进度。

## 使用方法

1. 复制此模板到项目根目录，命名为 `STATE.md`
2. 填写任务信息和计划
3. 按照原子任务顺序执行
4. 每完成一个任务，更新 STATE.md
5. 完成后删除 STATE.md

```markdown

## 任务清单
- [ ] 任务 1：[描述] (预计 X 分钟)
- [ ] 任务 2：[描述] (预计 X 分钟)
- [ ] 任务 3：[描述] (预计 X 分钟)
- [ ] 任务 4：[描述] (预计 X 分钟)

## 进度
当前：任务 [X]/[总数]
完成：[X]%

## 备注
[任何重要信息]
```

## 何时使用 STATE.md

### ✅ 需要使用
- 新功能开发（> 3 个文件）
- 大型重构（影响多个模块）
- Bug 修复（涉及多个文件）
- 性能优化

### ❌ 不需要使用
- 单个文件修改
- 简单 Bug 修复
- 文档更新
- 配置调整

---

## 使用 end-to-end-delivery skill

对于复杂任务，使用 `end-to-end-delivery` skill 自动管理 STATE.md：

1. 使用 `brainstorming` skill 探索需求
2. 调用 `end-to-end-delivery` skill
3. 系统自动创建和管理 STATE.md
4. 完成后自动删除

```markdown
## 目标
让用户通过配对码或二维码与 Bot 建立配对关系

## 任务清单
- [ ] 任务 1：创建配对服务 (20 分钟)
- [ ] 任务 2：实现配对码生成 (15 分钟)
- [ ] 任务 3：实现二维码显示 (10 分钟)
- [ ] 任务 4：添加配对状态管理 (15 分钟)

## 进度
当前：任务 2/4
完成：50%

## 备注
- 使用 Supabase Realtime 更新状态
- 需要处理 Bot 离线情况
```
