## Quick Start

### 1. Prerequisites

- macOS with Xcode 15+
- XcodeGen: `brew install xcodegen`
- Bundle: `brew install swiftgen` (or use the bundled `project.yml`)
- Apple Developer account with valid provisioning profile

### 2. Generate Xcode Project

```bash
cd ios/TRIX3DCompanion
xcodegen generate
open TRIX3DCompanion.xcodeproj
```

### 3. Configure Secrets

Create `Config/Secrets.swift` (not committed to version control):

```swift
enum SupabaseConfig {
    static let url = "https://your-project.supabase.co"
    static let anonKey = "your-anon-key"
}
```

### 4. Build

```bash
xcodebuild -project TRIX3DCompanion.xcodeproj \
  -scheme TRIX3DCompanion \
  -configuration Debug \
  -destination 'generic/platform=iOS Simulator' \
  build
```
