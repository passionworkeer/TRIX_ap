## 1. 敏感数据类型识别

本节详细列出项目中处理的所有敏感数据类型及其安全等级。

### 1.1 认证凭据

| 数据类型 | 安全等级 | 描述 | 存储位置 |
|---------|---------|------|---------|
| Access Token | **极高** | 用户访问 API 的凭证 | Keychain |
| Refresh Token | **极高** | 用于刷新 Access Token | Keychain |
| Session Token | **极高** | 会话标识符 | Keychain |
| 用户密码 | **极高** | 登录密码（仅在登录时传输） | 仅传输，不存储 |
| OAuth Tokens | **极高** | Apple/WeChat 第三方登录令牌 | Keychain |
| Device ID | **高** | 设备唯一标识符（加密随机生成） | Keychain |

### 1.2 用户个人信息

| 数据类型 | 安全等级 | 描述 | 存储位置 |
|---------|---------|------|---------|
| 用户 ID | **高** | 用户唯一标识符 | Keychain |
| 用户名 | **中** | 登录用户名 | UserDefaults (缓存) |
| 邮箱地址 | **中** | 用户邮箱 | UserDefaults (缓存) |
| 全名/显示名 | **中** | 用户显示名称 | UserDefaults (缓存) |
| 头像 URL | **低** | 头像图片链接 | UserDefaults (缓存) |
| 个人简介 | **低** | 用户个人简介 | UserDefaults (缓存) |
| 积分余额 | **中** | 用户积分 | UserDefaults (缓存) |
| 学习时长 | **低** | 累计学习时间 | UserDefaults (缓存) |

### 1.3 支付信息

| 数据类型 | 安全等级 | 描述 | 存储位置 |
|---------|---------|------|---------|
| 交易 ID | **高** | 支付交易标识符 | 仅传输给服务器验证 |
| 订单信息 | **中** | 本地订单缓存 | 内存 (不持久化) |
| 应用内购买 | **极高** | Apple IAP | StoreKit (Apple 处理) |

### 1.4 位置信息

| 数据类型 | 安全等级 | 描述 | 存储位置 |
|---------|---------|------|---------|
| 最后已知位置 | **中** | 经纬度坐标 | UserDefaults |
| 位置精度 | **低** | 定位精度 | UserDefaults |

### 1.5 通讯内容

| 数据类型 | 安全等级 | 描述 | 存储位置 |
|---------|---------|------|---------|
| 聊天消息 | **高** | 用户聊天内容 | SQLite (AES-256 加密) |
| 消息媒体 URL | **中** | 图片/语音等媒体链接 | SQLite |

### 2.3 存储位置详细说明

#### Keychain (最高安全级别)

**存储内容**:
- `com.trix3d.accessToken` - Access Token
- `com.trix3d.refreshToken` - Refresh Token
- `com.trix3d.sessionToken` - Session Token
- `com.trix3d.userId` - 用户 ID
- `com.trix3d.deviceId` - 加密生成的设备 ID
- `com.trix3d.biometricEnabled` - 生物识别启用状态
- `com.trix3d.pairedDeviceId` - 配对设备 ID
- `com.trix3d.pairedDeviceName` - 配对设备名称
- `com.trix3d.isPaired` - 配对状态
- `oauth_token_apple` - Apple OAuth Token
- `oauth_token_wechat` - WeChat OAuth Token
- `com.trix3d.dbEncryptionKey` - 数据库加密密钥

**安全配置**:
```swift
keychain = Keychain(service: bundleIdentifier)
    .synchronizable(false)  // 不同步到 iCloud
    .accessibility(.whenUnlockedThisDeviceOnly)  // 仅在设备解锁时访问
```

#### UserDefaults (中等级别)

**存储内容** (非敏感配置):
- `cachedUser` - 缓存的用户信息 (JSON 编码)
- `cachedChatRooms` - 缓存的聊天房间列表
- `cachedStudyStats` - 缓存的学习统计
- `cachedPointsStats` - 缓存的积分统计
- `lastKnownLatitude/Longitude` - 位置坐标 (精确到约 1km)
- 应用设置: 主题、语言、通知开关等

#### SQLite 数据库 (高安全级别)

**表结构**:
- `messages` - 聊天消息 (内容字段 AES-256 加密)
- `chat_rooms` - 聊天房间
- `study_sessions` - 学习会话
- `points_history` - 积分历史 (描述字段加密)

**加密实现**:
- 256 位 AES-CBC 加密
- 随机 IV (每次加密生成)
- 加密密钥存储在 Keychain 中

### 2.4 传输方式

#### HTTPS (所有 API 请求)
- 使用 Alamofire 库
- SSL Certificate Pinning (SSL pinning manager)
- 请求超时: 30 秒
- 资源超时: 60 秒

#### WebSocket (WSS)
- 使用 Starscream 库
- 心跳间隔: 30 秒
- 重连策略: 指数退避 (最大 30 秒)
- 消息去重: 最多缓存 1000 条消息 ID
- 速率限制: 每秒最多 50 条消息

## 3. 安全问题检查

### 3.1 已解决的安全问题

| 问题类型 | 状态 | 解决方案 | 文件位置 |
|---------|------|---------|---------|
| 凭据明文存储 | **已解决** | Keychain + `whenUnlockedThisDeviceOnly` | `KeychainManager.swift` |
| 数据库明文存储 | **已解决** | AES-256-CBC 加密 | `DatabaseManager.swift` |
| HTTPS 证书劫持 | **已解决** | SSL Pinning | `APIClient.swift` |
| 日志泄露敏感信息 | **已解决** | SecureLogger 生产环境脱敏 | `SecureLogger.swift` |
| 消息内容泄露 | **已解决** | 数据库加密存储 | `DatabaseManager.swift` |
| 设备 ID 预测 | **已解决** | 加密随机生成 (SecRandomCopyBytes) | `KeychainManager.swift` |
| Token 内存暴露 | **已解决** | 自动刷新 + 过期清理 | `AuthService.swift` |
| OAuth 令牌泄露 | **已解决** | Keychain 存储 | `OAuthManager.swift` |
| 支付信息处理 | **已解决** | Apple StoreKit 处理，应用不接触卡号 | `PaymentService.swift` |
| 位置隐私 | **已解决** | 精度降低 (生产环境 1km) | `SecureLogger.swift` |
| WebSocket 注入 | **已解决** | 消息验证 + 白名单 | `WebSocketManager.swift` |

### 3.2 潜在安全问题

| 问题类型 | 风险等级 | 描述 | 建议 |
|---------|---------|------|------|
| UserDefaults 缓存用户信息 | **低** | 邮箱、用户名等以明文存储在 UserDefaults | 考虑加密或移到 Keychain |
| 旧配对数据残留 | **低** | 旧版 UserDefaults 残留配对信息 | 已实现迁移功能，建议清理旧数据 |
| 内存中 Token 残留 | **低** | Token 在内存中保留直到登出或过期 | 可接受，符合行业标准 |
| 登录密码传输 | **中** | 密码在登录请求中传输 | 已使用 HTTPS，建议增加额外加密层 |

- Token 刷新后旧 Token 自动失效
- 不在全局变量中存储敏感信息
