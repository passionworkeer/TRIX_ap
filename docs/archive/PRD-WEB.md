## 1. 产品概述

### 1.1 产品定位

Web 端是 TRIX 3D Companion 的跨平台入口，用户可以通过浏览器访问并使用所有核心功能。Web 端强调**快速访问**和**桌面级体验**。

### 1.2 核心使用场景

| 场景 | 描述 |
|-----|------|
| 桌面学习 | 在电脑上使用番茄钟学习 |
| 快速聊天 | 与 AI 机器人或好友即时通讯 |
| 好友管理 | 添加、管理好友，查看状态 |
| 商城购物 | 浏览和购买虚拟商品 |
| 地图打卡 | 查看和管理打卡地点 |

## 7. 性能优化

### 7.1 加载优化

| 优化项 | 方案 |
|-----|------|
| 代码分割 | React.lazy + Suspense |
| 路由懒加载 | 每个页面独立 chunk |
| 图片懒加载 | loading="lazy" |
| 资源预加载 | ResourcePreloader hook |

### 7.2 运行时优化

| 优化项 | 方案 |
|-----|------|
| 状态更新 | useMemo, useCallback |
| 列表渲染 | Virtual scrolling |
| 图片缓存 | 浏览器缓存 + CDN |
| WebSocket | 心跳保活 |

### 7.3 性能指标

| 指标 | 目标 | 当前 |
|-----|------|------|
| 首屏加载 (LCP) | < 1.5s | ~1.2s |
| 交互延迟 (FID) | < 100ms | ~50ms |
| 包体积 (JS) | < 500KB | ~420KB |

## 11. 常见问题

### Q: Web 端和 iOS 端数据同步吗？
A: 是的，通过 Supabase 数据库实时同步，配对后可通过 WebSocket 跨设备通信。

### Q: 支持哪些浏览器？
A: 支持 Chrome 90+, Safari 15+, Edge 90+。

### Q: 如何保持登录状态？
A: 使用 Token 存储在 localStorage，并支持自动刷新。
