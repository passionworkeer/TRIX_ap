# TRIX Channel 修复记录

2026-03-13

## 修复内容

### 1. 流式消息截断问题 (openclaw-skills/trix-channel/index.js)

**问题**：Gateway 返回的消息被截断，特别是使用 CLI fallback 时只能获取到部分内容。

**解决方案**：添加流式数据缓冲机制
- 新增 `gatewayStreamBuffers` Map 存储流式数据
- 添加 `appendGatewayStreamChunk()` - 在非最终状态时累加消息
- 添加 `takeGatewayStreamText()` - 获取并清除缓冲
- 添加 `mergeGatewayTexts()` - 合并缓冲消息和最终消息
- 修改 `isGatewayFinalState()` 默认返回 false，避免误判

**关键改动**：
- 非最终状态的消息会被缓存
- 最终状态时合并完整内容
- 清理过期缓冲数据

### 2. 错误状态显示问题 (src/contexts/ClawbotChannelContext.tsx)

**问题**：聊天界面的 TRIX Bot 状态一直显示 Error，但实际 bot 能正常工作。

**原因**：
- 收到任何 socket error 事件时，status 都会被设为 'ERROR'
- 消息发送失败等非连接错误也会导致状态变为 ERROR
- 之后没有恢复机制

**解决方案**：
- 修改 error 事件处理逻辑
- 只在连接相关错误（CONNECT_ERROR, CONNECTION_FAILED）时更新状态为 ERROR
- 消息错误不影响连接状态显示

### 3. 文件收发功能 (openclaw-skills/trix-channel/index.js)

**问题**：OpenClaw 显示 "当前是在 webchat 会话，capabilities=none"，无法收发文件。

**解决方案**：
在 capabilities 中添加 media 支持：
```javascript
capabilities: {
  chatTypes: ['direct'],
  media: {
    upload: ['image/*', 'audio/*', 'video/*'],
    download: ['image/*', 'audio/*', 'video/*']
  }
}
```
