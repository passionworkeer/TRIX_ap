# TRIX Web MySQL 作业版需求分析

## 1. 课题名称

TRIX 3D Companion 学习陪伴与个人管理 Web 系统。

## 2. 选题说明

本项目按数据库 Web 应用综合实验要求自选题实现，定位为面向学生的学习陪伴与个人管理系统。系统保留 TRIX 既有 Web 端产品方向，在课堂作业版本中重点突出 MySQL 数据库、登录验证、数据增删改查、统计展示和现场演示能力。

## 3. 用户角色

| 角色 | 说明 | 主要操作 |
|------|------|----------|
| 学生用户 | 系统主要使用者 | 注册登录、维护资料、管理待办、记录学习、聊天、查看通知 |
| 学习搭子 | 学生之间的好友关系 | 互相查看学习状态、发送聊天消息、接收好友通知 |
| 演示管理员 | 课堂演示账号 | 导入种子数据、演示核心业务流程、检查 MySQL 数据变化 |

## 4. 功能需求

### 4.1 登录与用户资料

- 支持邮箱和密码登录。
- 支持注册新用户，密码使用 scrypt 哈希保存到 MySQL。
- 登录成功后通过后端签发的 httpOnly Cookie 维持 Web 会话。
- 用户可以查看和修改个人资料，包括昵称、简介、学校、年级、头像等。

### 4.2 首页与学习概览

- 首页展示当前用户、学习陪伴入口和核心菜单。
- 展示学习状态、积分、通知等与用户相关的数据。
- 保留 TRIX 既有 Web 路由和菜单，确保课堂演示时所有入口可访问。

### 4.3 待办与学习记录

- 待办任务支持新增、查询、修改、删除。
- 待办包含标题、描述、优先级、完成状态、截止时间和标签。
- 学习记录支持新增和查询。
- 学习统计接口汇总当天学习时长、总学习时长和会话数量。

### 4.4 好友与聊天

- 支持好友列表、好友请求和会话列表。
- 聊天消息保存到 MySQL，包含发送者、接收者、会话 ID、正文、已读状态和媒体元数据字段。
- 后端对聊天接口做用户身份隔离，防止伪造发送者或读取无关会话。

### 4.5 积分商城与衣柜

- 用户积分、积分流水、商城商品和已购买商品保存到 MySQL。
- 衣柜包含可购买外观、用户已拥有外观和当前穿戴状态。
- 课堂演示可展示商品列表、积分余额和用户资产数据。

### 4.6 地图与通知邮件

- 地点、用户位置、位置分享设置、收藏地点保存到 MySQL。
- 通知和站内邮件支持按当前登录用户查询。
- 系统通知、好友请求和学习提醒均通过数据库表统一管理。

## 5. 非功能需求

| 类型 | 要求 |
|------|------|
| 数据库 | 使用 MySQL 8.x，表结构具备主键、外键、唯一约束和索引 |
| 安全 | 密码不明文保存，登录态由后端签发，用户数据按当前用户隔离 |
| 可演示 | 本机可启动 Web、API、MySQL，并可完成增删改查和统计展示 |
| 可维护 | 前端通过统一 API Client 访问后端，后端使用参数化 SQL |
| 兼容 | 作业版只覆盖 Web 端，不破坏 iOS / Desktop 目录结构 |

## 6. 菜单与数据表映射

| Web 功能 | 主要数据表 | 操作类型 |
|----------|------------|----------|
| 登录注册 | `users`, `profiles` | 增、查 |
| 个人资料 | `profiles` | 查、改 |
| 待办 | `todos` | 增、删、改、查 |
| 学习记录 | `study_sessions`, `study_rooms`, `study_room_members` | 增、查、统计 |
| 好友聊天 | `friends`, `friend_requests`, `chat_messages`, `unread_counts` | 增、改、查 |
| 积分商城 | `user_points`, `point_transactions`, `mall_items`, `user_purchased_items` | 增、改、查 |
| 衣柜 | `outfits`, `user_outfits` | 增、改、查 |
| 地图 | `places`, `user_locations`, `user_location_settings`, `user_favorite_places` | 增、改、查 |
| 通知邮件 | `notifications`, `mails` | 增、改、查 |

## 7. 验收标准

- `npm run build` 通过。
- `GET /api/db/health` 返回 `{"ok":true}`。
- 使用 `test1@trix.app / 123456` 可登录 Web 首页。
- 主要菜单可进入且能加载 MySQL 数据。
- 至少演示一个新增、一个修改、一个删除和一个统计查询。
- MySQL 中能观察到对应数据变化。
