## 三端介绍

### 1. App 端 (Trix-3D-Companion Web 应用)

**职责**:
- 用户界面展示
- 用户交互处理
- 消息收发
- 设备配对管理

**核心目录结构**:
```
src/
├── contexts/              # React Context 状态管理
│   ├── ClawbotChannelContext.tsx
│   ├── NanobotContext.tsx
│   └── QRCodePairingContext.tsx
├── services/              # 通信服务层
│   ├── ClawbotChannelBridge.ts
│   ├── NanobotBridge.ts
│   └── clawbotPairingService.ts
├── screens/               # 页面组件
│   ├── Pairing.tsx       # Clawbot 配对页面
│   ├── NanobotPairing.tsx # Nanobot 配对页面
│   ├── QRCodePairing.tsx # 二维码配对页面
│   └── ChatDetail.tsx    # 聊天详情页
└── types/
    └── clawbot.ts        # 类型定义
```

### 2. Clawbot Channel 端 (云端配对服务)

**服务器地址**: `wss://m.jmtrick.com`

**职责**:
- 设备配对管理
- 配对码生成和验证
- 消息中转
- 设备在线状态维护

**通信协议**: Socket.IO

**核心功能**:
- `app_register` - App 注册
- `pair_with_code` - 配对码配对
- `pair_with_token` - Token 配对
- `app_message` - 消息发送
- `bot_message` - Bot 消息接收
- `ping/pong` - 心跳保活

### 3. Nanobot 端 (AI 机器人服务)

**服务器地址**: `ws://47.243.55.130:8766`

**职责**:
- AI 对话响应
- 聊天消息处理
- 智能回复生成

**通信协议**: 原生 WebSocket

**核心功能**:
- `register` - 设备注册
- `app_pairing` - 配对请求
- `chat_message` - 聊天消息
- `chat_response` - AI 响应
- `ping/pong` - 心跳

### Bridge 服务层

**文件**: `src/services/ClawbotChannelBridge.ts`

#### 类结构

```typescript
class ClawbotChannelBridge {
  // Socket.IO 实例
  private socket: Socket | null = null;

  // 连接状态

  public paired: boolean = false;

  // 设备 ID

  private heartbeatInterval: number = 30000; // 30 秒

  // 重连相关

  // 事件监听器
  private eventListeners: Map<string, Set<EventCallback>> = new Map();
}
```

#### 核心方法

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| `connect()` | - | `Promise<void>` | 连接到服务器 |
| `disconnect()` | - | `void` | 断开连接 |
| `pairWithCode(code)` | `string` | `Promise<{success, pairingId, status}>` | 配对码配对 |
| `pairWithToken(token)` | `string` | `Promise<{success, pairingId, status}>` | Token 配对 |
| `sendMessage(content, contentType, mediaUrl)` | `string, string, string?` | `Promise<void>` | 发送消息 |
| `uploadMedia(file)` | `File\|Blob` | `Promise<string>` | 上传媒体文件 |
| `unpair()` | - | `void` | 解除配对 |
| `isConnected()` | - | `boolean` | 检查连接状态 |
| `isPaired()` | - | `boolean` | 检查配对状态 |
| `on(event, callback)` | `string, Function` | `void` | 添加事件监听器 |
| `off(event, callback)` | `string, Function` | `void` | 移除事件监听器 |

#### Socket.IO 事件

**客户端发送事件**:

| 事件名 | 数据结构 | 说明 |
|--------|----------|------|
| `app_register` | `{ userId: string }` | App 注册 |
| `pair_with_code` | `{ code: string, userId: string }` | 配对码配对 |
| `pair_with_token` | `{ token: string, userId: string }` | Token 配对 |
| `app_message` | `{ content, contentType, mediaUrl, messageId }` | 发送消息 |
| `ping` | - | 心跳请求 |
| `unpair` | - | 解除配对 |

**服务器推送事件**:

| 事件名 | 数据结构 | 说明 |
|--------|----------|------|
| `pairing_success` | `{ deviceId, deviceName }` | 配对成功 |
| `bot_message` | `{ content, contentType, mediaUrl, timestamp }` | Bot 消息 |
| `bot_offline` | `{ deviceId, message, timestamp }` | Bot 离线 |
| `bot_online` | `{ deviceId, message, timestamp }` | Bot 上线 |
| `unpaired` | - | 被解绑 |
| `pong` | - | 心跳响应 |
| `message_sent` | `{ success, messageId, error }` | 消息发送确认 |

## 二维码配对流程

### 服务层

**文件**: `src/services/clawbotPairingService.ts`

#### 配对模式

**1. 直接连接模式（webchat 模式）**

适用于已经知晓 Gateway URL 和 Token 的场景：

```typescript
// 直接保存配置，跳过 HTTP API 配对
clawbotPairingService.directConnect(
  'ws://localhost:18789',
  'your-auth-token'
);
```

**2. HTTP API 模式**

通过 Gateway HTTP API 发起配对请求：

```typescript
// 发送配对请求到 Gateway
await clawbotPairingService.generatePairingRequest(
  'My Device Name',
  'pairing-token'
);
```

**3. Supabase 轮询模式**

通过 Supabase 作为中间存储，Gateway 轮询获取配对请求：

```typescript
// 存储到 Supabase
await supabase.from('pairing_requests').insert([...]);

// 轮询配对状态
await clawbotPairingService.pollPairingStatus(
  requestId,
  (response) => {
    // 处理状态变化
  }
);
```

## 数据结构详解

### Clawbot 类型定义

**文件**: `src/types/clawbot.ts`

#### 基础类型

```typescript
/** 配对状态 */
type PairingStatus = 'pending' | 'approved' | 'denied' | 'cancelled' | 'expired';

/** 设备类型 */
type DeviceType = 'mobile' | 'desktop' | 'tablet' | 'web';

/** 连接状态 */
type ConnectionStatus = 'DISCONNECTED' | 'CONNECTING' | 'CONNECTED' | 'AUTH_FAILED' | 'ERROR' | 'RECONNECTING';

/** WebSocket 消息类型 */
type WebSocketMessageType =
  | 'ping'           // 心跳请求
  | 'pong'           // 心跳响应
  | 'pairing.request'   // 配对请求
  | 'pairing.confirm'   // 配对确认
  | 'pairing.success'   // 配对成功
  | 'message'        // 普通消息
  | 'command'        // 命令消息
  | 'error'          // 错误通知
  | 'connect.challenge' // 连接挑战
  | 'req'            // 请求
  | 'res';           // 响应

/** 消息内容类型 */
type MessageContentType = 'text' | 'image' | 'video' | 'audio' | 'mixed' | 'command';
```

#### 配对相关

```typescript
/** 二维码数据 */
interface QRCodeData {
  gatewayUrl: string;        // Gateway WebSocket URL
  pairingToken: string;      // 配对 Token
  requestId: string;         // 请求 ID
  expiresAt: string;         // 过期时间 (ISO 8601)
}

/** 配对请求 */
interface PairingRequest {
  requestId: string;         // 请求唯一 ID
  deviceName: string;        // 设备名称
  deviceType: DeviceType;    // 设备类型
  timestamp: number;         // 创建时间戳
  status: PairingStatus;     // 当前状态
  deviceId?: string;         // 设备 ID
  device_token?: string;     // 配对 Token
  message?: string;          // 附加信息
  metadata?: PairingMetadata; // 元数据
}

/** 配对响应 */
```

## 常见问题

### Q1: 如何切换 Clawbot Channel 和 Nanobot？

在 `ChatDetail.tsx` 中，根据 `friendId` 判断使用哪个 Bridge：

```typescript
if (state.friendId === 'clawbot') {
  // 使用 ClawbotChannelContext
  const { sendMessage } = useClawbotChannel();
} else if (state.friendId === 'nanobot') {
  // 使用 NanobotContext
  const { sendMessage } = useNanobot();
}
```

### Q2: 如何实现消息确认机制？

**ClawbotChannelBridge** 使用消息 ID 匹配确认：

```typescript
// 1. 发送消息时附带 messageId
socket.emit('app_message', { content, messageId });

// 2. 监听确认事件，只处理匹配的消息ID
socket.on('message_sent', (response) => {
  if (response.messageId === messageId) {
    // 处理确认
  }
});
```

### Q3: 心跳机制是如何工作的？

两个 Bridge 都实现了心跳机制：

1. **ClawbotChannelBridge**: 每 30 秒发送 `ping`，期待 60 秒内收到 `pong`
2. **NanobotBridge**: 每 30 秒发送 `ping` 消息

如果超时未收到响应，会自动重连：

```typescript
// ClawbotChannelBridge 示例
if (Date.now() - this.lastPongTime > 60000) {
  this.socket?.disconnect();
  this.socket?.connect();
}
```

### Q4: 配对状态有哪几种？

```typescript
type PairingStatus = 'pending'      // 等待确认
                    | 'approved'     // 已批准
                    | 'denied'       // 已拒绝
                    | 'cancelled'    // 已取消
                    | 'expired';     // 已过期
```

### Q5: 如何调试通信问题？

1. **检查连接状态**:
```typescript
const { isConnected, isPaired, status } = useClawbotChannel();
console.log('连接状态:', status, '已配对:', isPaired);
```

2. **监听错误事件**:
```typescript
clawbotChannelBridge.on('error', (error) => {
  console.error('ClawbotChannel 错误:', error);
});
```

3. **查看 localStorage**:
```javascript
console.log('设备 Token:', localStorage.getItem('clawbot_device_token'));
console.log('Gateway URL:', localStorage.getItem('clawbot_gateway_url'));
```

### Q6: Nanobot 配对码在哪里获取？

Nanobot 配对码由 Nanobot 服务端生成：

1. 在电脑上运行 Nanobot
2. Nanobot 会生成一个 8 位配对码（例如：A1B2C3D4）
3. 在 App 中输入该配对码进行配对
