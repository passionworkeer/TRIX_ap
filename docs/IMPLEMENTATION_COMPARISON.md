#### 2. **数据持久化缺失**（关键问题）⚠️

| 理想实现 | 当前实现 | 改进建议 |
|---------|---------|---------|
| 数据库存储配对关系 | 内存存储配对关系 | 优先级：⭐⭐⭐⭐⭐<br>建议：**必须实现** |

**影响**（严重）：
- ❌ 服务器重启后，所有用户需要重新配对
- ❌ 无法实现"永久绑定"
- ❌ 无法支持多设备同时配对（内存有限）
- ❌ 无法实现账号系统和权限管理

**解决方案**：
```python
# 在 cloud_server.py 中添加数据库支持
import sqlite3

# 初始化数据库
def init_db():
    conn = sqlite3.connect('/tmp/nanobot.db')
    c = conn.cursor()
    c.execute('''
        CREATE TABLE IF NOT EXISTS pairings (
            code TEXT PRIMARY KEY,
            nanobot_device_id TEXT,
            app_device_id TEXT,
            user_id TEXT,
            created_at TIMESTAMP,
            status TEXT
        )
    ''')
    conn.commit()
    return conn

# 保存配对关系到数据库
def save_pairing(code, nanobot_device_id, app_device_id, user_id):
    c.execute('''
        INSERT INTO pairings VALUES (?, ?, ?, ?, ?, ?)
    ''', (code, nanobot_device_id, app_device_id, user_id, datetime.now(), 'active'))
    conn.commit()

# 查询配对关系
def query_pairing(user_id):
    c.execute('SELECT * FROM pairings WHERE user_id = ?', (user_id,))
    return c.fetchone()
```
