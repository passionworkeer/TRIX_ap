## 1. 产品概述

### 1.1 产品定位

**TRIX 3D Companion** 是一款面向年轻用户的 **AI 陪伴学习应用**，核心理念是 **"Zero UI" 沉浸式交互**。

产品通过 AI 机器人陪伴 + 自习室社交 + 任务管理等功能，帮助用户：
- 🤖 **AI 陪伴**：与 AI 机器人实时对话，获得学习动力
- 📚 **专注学习**：番茄钟计时 + 双人陪伴模式，提升学习效率
- 👥 **社交学习**：加入自习室，与好友一起学习
- 📍 **位置社交**：地图打卡，查看好友位置
- 🛒 **积分商城**：学习赚积分，兑换虚拟商品

### 1.2 目标用户

| 用户群体 | 特征 | 核心需求 |
|---------|------|---------|
| **学生党** | 15-25 岁，大学生/高中生 | 自习监督、学习陪伴、社交互动 |
| **考研党** | 22-28 岁，考研人群 | 长时间专注、互相监督、进度管理 |
| **职场新人** | 22-30 岁 | 技能提升、时间管理、碎片化学习 |

### 1.3 核心价值

1. **AI 陪伴**：不再孤单学习，AI 机器人随时响应
2. **社交动力**：好友陪伴学习，互相监督不孤单
3. **数据激励**：积分系统、可视化统计，持续获得正反馈
4. **沉浸体验**：毛玻璃 UI、流畅动画，学习也是一种享受

### 2.2 核心功能详述

#### 2.2.1 AI 对话 (Chat)

**功能描述**：
用户可以与 AI 机器人进行实时对话，获得学习建议、陪伴聊天、任务提醒等服务。

**关键特性**：
- 实时 WebSocket 消息推送
- 文字 + 语音消息
- AI 智能动作建议（继续学习、休息提醒等）
- 消息历史存储
- 离线消息同步

**技术实现**：
- WebSocket: Socket.IO
- AI 集成: OpenClaw Gateway
- 消息存储: Supabase (chat_messages 表)
- 离线同步: 增量同步机制

---

#### 2.2.2 自习功能 (Study)

**功能描述**：
提供番茄钟计时器，支持单人专注和双人陪伴模式，记录学习数据并可视化展示。

**关键特性**：
- 番茄钟计时（25/5 分钟循环）
- 双人陪伴模式（实时同步状态）
- 学习室（多人在线自习）
- 专注数据统计
- 积分奖励（每分钟 2 积分）

**技术实现**：
- 计时器: 本地定时器 + 状态同步
- 双人模式: Supabase Realtime 实时推送
- 学习室: WebSocket 房间管理
- 数据存储: study_sessions, study_rooms 表

---

#### 2.2.3 好友系统 (Friends)

**功能描述**：
用户可以添加好友，查看好友在线状态，实时同步学习状态。

**关键特性**：
- 搜索/添加好友
- 好友列表（在线/离线状态）
- 学习状态同步
- 位置共享（可选）
- 黑名单/拉黑功能

**技术实现**：
- 好友关系: friends 表
- 状态同步: Supabase Realtime
- 位置: 地理坐标存储 + 隐私控制

---

#### 2.2.4 积分商城 (Points Mall)

**功能描述**：
用户通过学习获得积分，可以在商城中兑换虚拟商品（头像框、主题、道具等）。

**关键特性**：
- 积分获取（学习、签到、任务）
- 商品展示（虚拟商品）
- 积分扣除购买
- 购买记录

**技术实现**：
- 积分服务: PointsService
- 交易记录: points_transactions 表
- 商品库存: mall_items 表

---

#### 2.2.5 设备配对 (Pairing)

**功能描述**：
将 iOS 设备与 Web 端配对，实现跨设备同步和数据共享。

**关键特性**：
- QR 码配对
- 6 位数字配对码
- 配对状态管理
- 解除配对

**技术实现**：
- 配对服务: pairingService.js
- 配对存储: pairings 表
- 消息路由: 配对设备间消息转发

---

#### 2.2.6 换装系统 (Wardrobe)

**功能描述**：
用户可以购买和装备虚拟服装/配饰，个性化展示形象。

**关键特性**：
- 商品浏览
- 积分购买
- 装备管理
- 形象展示

## 4. 数据模型

### 4.1 核心表

| 表名 | 描述 | 主要字段 |
|-----|------|---------|
| `users` | 用户信息 | id, email, username, avatar_url |
| `profiles` | 用户资料扩展 | user_id, total_study_time, points |
| `friends` | 好友关系 | user_id, friend_id, status |
| `chat_messages` | 聊天消息 | from_user_id, to_user_id, content, type |
| `study_sessions` | 学习记录 | user_id, start_time, duration, points |
| `study_rooms` | 学习室 | host_id, is_active |
| `study_room_members` | 学习室成员 | room_id, user_id, status |
| `notifications` | 通知 | user_id, type, content, read |
| `pairings` | 设备配对 | user_id, device_id, status |
| `points_transactions` | 积分交易 | user_id, amount, type |
| `mall_items` | 商城商品 | name, price, type |

## 7. 安全措施

### 7.1 认证与授权

- JWT Token 鉴权
- Token 刷新机制
- OAuth 2.0 (Apple, WeChat)
- 设备配对验证

### 7.2 数据安全

- HTTPS 强制
- SSL Certificate Pinning (iOS)
- Keychain 存储敏感信息
- 数据库 RLS (Row Level Security)

### 7.3 网络安全

- CORS 白名单
- Rate Limiting
- 请求去重
- SQL 参数化查询
