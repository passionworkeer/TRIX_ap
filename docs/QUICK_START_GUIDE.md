```bash
cd E:\desktop\trix-3d-companion
```

浏览器打开: http://localhost:5173

## 📱 功能演示路径

### 1️⃣ 聊天历史记录 (Chat History)

**测试步骤:**
1. 点击右下角紫色聊天气泡 → 进入 Clawbot 对话
2. 发送几条消息（例如："你好"、"帮我解释一下算法"）
3. 刷新页面 (F5)
4. ✅ **验证**: 之前的对话完整保留！

**也可以测试好友聊天:**
1. 底部导航 → 点击"聊天"图标
2. 点击任意好友 (例如：爱丽丝)
3. 发送消息
4. 返回后再进入 → 历史记录保留

---

### 2️⃣ 项目进度管理 (Project Progress)

**查看项目:**
1. 在 **Home 首页** 向下滚动
2. 看到 **"数据结构课程设计"** 卡片
3. 显示: 
   - 50% 进度条（带流光动画）
   - 已完成 5 / 待完成 5 / 高优先级 2

**操作任务:**
1. 点击卡片右上角的 **下箭头按钮** 展开
2. 看到 10 个任务列表
3. 点击任意未完成任务 → 变为绿色 ✅
4. 再次点击 → 恢复为待完成 ⭕
5. 进度百分比自动更新！

**任务特性:**
- 🔴 高优先级 (红色标签)
- 🟠 中优先级 (橙色标签)
- 🔵 低优先级 (蓝色标签)
- ⏰ 显示到期时间 (明天到期 / 2天后 等)

### 3️⃣ 好友自习室 (Study Room)

**进入自习室:**
1. 在 **Home 首页** 找到 **"好友自习室"** 卡片
2. 显示在线人数徽章 (例如：3 人在线)
3. 点击整个卡片 → 弹出自习室弹窗

**自习室功能:**
- 📚 看到正在学习的好友卡片:
  - **爱丽丝** - 💪 努力 - 已学习 1小时5分钟
  - **Carol** - 🔥 学霸 - 已学习 2小时15分钟
  - **David** - 📚 加油 - 已学习 45分钟

- 🎯 学习等级系统:
  - 📚 **加油** (< 1小时) - 青蓝渐变
  - 💪 **努力** (1-2小时) - 橙红渐变
  - 🔥 **学霸** (> 2小时) - 紫粉渐变

- 💬 **点击"发送消息"按钮** → 直接跳转到对应好友的聊天页面

**离线好友:**
- 向下滚动看到 **"离线好友"** 区域
- 显示 Bob 和 Emma (半透明头像)
- 点击也可以发送消息

### 4️⃣ 邮件系统 (Mail)

**打开邮件:**
1. Home 页面右上角点击 **📧 邮件图标**
2. 红色徽章显示未读数量 (默认 2 封未读)
3. 侧边弹出邮件面板

**邮件列表:**
左侧显示 4 封邮件:
- 📧 **教务处** - 期末考试安排通知 (未读，蓝色背景)
- 📚 **图书馆** - 图书到期提醒 (未读，蓝色背景)
- 👤 **Carol** - 项目协作邀请 (已读)
- 🎉 **TRIX Team** - 欢迎使用 TRIX (已读)

**操作邮件:**
1. 点击任意邮件 → 右侧显示详情
2. 未读邮件点击后自动标记为已读 ✅
3. 点击右上角 **🗑️ 删除按钮** 删除邮件
4. 点击 **X** 关闭面板

---

### 5️⃣ 通知系统 (Notifications)

**打开通知:**
1. Home 页面右上角点击 **🔔 通知图标**
2. 红色徽章显示未读数量 (默认 3 条未读)
3. 侧边弹出通知面板

**通知类型:**
- 👥 **好友请求** (绿色图标) - Frank 想要加你为好友
  - 有 **接受/拒绝** 按钮
- 💬 **消息通知** (青色图标) - Bob 发来消息
- ⚠️ **系统通知** (橙色图标) - TRIX v2.0 新功能

**操作通知:**
1. 点击单个通知 → 标记为已读
2. 点击右上角 **"✓ 全部已读"** → 所有通知变为已读
3. 未读通知有橙色高亮背景
4. 已读通知变为白色背景

## 🎨 设计风格特点

### 视觉效果
✅ **毛玻璃效果** - 所有弹窗和卡片都有 `backdrop-blur`  
✅ **圆角设计** - 统一使用 `rounded-2xl` / `rounded-3xl`  
✅ **渐变色** - 青蓝主色调 (`from-cyan-500 to-blue-600`)  
✅ **阴影层次** - `shadow-xl` 立体感  

### 动画效果
✅ **浮动动画** - Home 页面角色 (`animate-float`)  
✅ **脉动动画** - LIVE 标签 (`animate-pulse`)  
✅ **缩放动画** - 弹窗进入 (`animate-scaleIn`)  
✅ **滑入动画** - 侧边面板 (`animate-slideIn`)  
✅ **流光效果** - 进度条 (`animate-shimmer`)  
✅ **悬停缩放** - 卡片交互 (`hover:scale-[1.02]`)  

### 交互反馈
✅ **点击反馈** - 按钮按下缩放 (`active:scale-95`)  
✅ **悬停效果** - 颜色渐变和阴影变化  
✅ **状态变化** - 已读/未读的视觉区分  
✅ **实时更新** - 数字徽章每秒刷新

## 💾 数据持久化

所有数据都保存在 **localStorage**，关闭浏览器后再打开也不会丢失：

- 📝 **聊天历史** - `trix_chat_history_{friendId}`
- 👥 **好友列表** - `trix_friends`
- 📧 **邮件** - `trix_mails`
- 🔔 **通知** - `trix_notifications`
- 📊 **项目** - `trix_projects`

**清除数据 (如果需要重置):**
```javascript
// 浏览器控制台 (F12) 输入:
localStorage.clear()
location.reload()
```

## 🔧 开发者信息

### 文件结构
```
src/
  services/
    storageService.ts    # 本地存储服务
    projectService.ts    # 项目管理服务
  contexts/
    WebSocketContext.tsx # 全局 WebSocket (已有)
    AuthContext.tsx      # 认证上下文 (已有)

components/
  MailPanel.tsx          # 邮件面板
  NotificationPanel.tsx  # 通知面板
  ProjectProgress.tsx    # 项目进度
  StudyRoom.tsx          # 好友自习室
  (其他已有组件...)

screens/
  Home.tsx              # 首页 (集成所有新功能)
  Chat.tsx              # 聊天列表 (真实好友数据)
  ChatDetail.tsx        # 聊天详情 (历史记录)
  (其他已有页面...)
```

### 技术栈
- React 18 + TypeScript
- React Router v6
- Tailwind CSS
- Lucide Icons
- localStorage API
- WebSocket (全局单例)
