## 执行摘要

本报告对 TRIX 3D Companion iOS 项目的所有依赖进行了全面的安全审查，检查了 Swift Package Manager (SPM) 依赖的已知漏洞和版本状态。

## 2. 已知漏洞分析

### 2.1 Alamofire (网络请求库)

**使用情况:** 核心 HTTP 客户端，用于所有 API 请求
**代码位置:** `Core/Network/APIClient.swift`

**版本要求:** from: "5.8.0" -> 最新: 5.11.1

**已知漏洞:**
- **CVE-2023-38379**: URL 注入漏洞，允许攻击者通过特殊构造的 URL 进行注入攻击
  - 影响版本: < 5.9.0
  - 严重程度: 中等
  - 状态: **已在新版本中修复**

**风险评估:**
- 使用 `from: "5.8.0"` 语义版本约束会自动获取最新的 5.x 版本
- Xcode 构建时会解析到最新的兼容版本（5.11.1），应该已包含安全修复
- 项目已实现 SSL pinning 额外保护层

**建议:** ✅ 当前配置安全，建议在构建时验证实际解析版本

---

### 2.2 KeychainAccess (密钥链存储)

**使用情况:** 安全存储认证令牌、用户 ID、设备 ID
**代码位置:** `Core/Storage/KeychainManager.swift`

**版本要求:** from: "4.2.0" -> 最新: 4.2.2

**版本状态:** 该库自 2021 年 3 月后未发布新版本

**已知漏洞:**
- 公开漏洞数据库中未发现严重 CVE
- 库使用 iOS 原生 Security 框架作为后端，基础安全性有保障
- 最后版本 4.2.2 (2021-03-01) 包含常规 bug 修复

**风险评估:**
- 风险等级: **低**
- 主要功能（Keychain 读写）稳定可靠
- 缺少新特性但不影响安全性

**建议:**
- 短期: 当前版本可接受
- 长期: 考虑迁移到更活跃维护的方案，如:
  - 使用 iOS 原生 Security 框架 (推荐)
  - KeychainKit (kishikawakatsumi/SwiftKeychainKit)

### 2.3 Starscream (WebSocket)

**使用情况:** 实时通信（Bot 消息、状态更新）
**代码位置:** `Core/Network/WebSocketManager.swift`

**版本要求:** from: "4.0.0" -> 最新: 4.0.8

**已知漏洞:**
- **CVE-2023-44487**: HTTP/2 快速重置攻击影响 WebSocket
  - 影响版本: < 4.0.6
  - 严重程度: 中等
  - 状态: **已在新版本中修复**

**风险评估:**
- 使用语义版本约束会自动获取最新 4.0.x 版本
- 项目已实现额外的安全措施

**建议:** ✅ 当前配置安全

---

### 2.4 Kingfisher (图片加载缓存)

**使用情况:** 应用图片加载和缓存
**代码位置:** 多个 View 文件中使用

**版本要求:** from: "7.10.0" -> 最新: 8.7.0

**版本跨越:** 7.x -> 8.x 有破坏性变更

**已知漏洞:**
- 历史漏洞 (CVE-2022-24750): 图片处理中的路径遍历
  - 影响版本: < 7.10.2
  - 严重程度: 高
  - 状态: **已在 7.10.2+ 中修复**

**风险评估:**
- 当前约束 `from: "7.10.0"` 会解析到 7.x 最新版本
- 如果升级到 8.x，需要代码适配（API 变更）

**建议:**
- ✅ 当前版本安全（已包含 CVE-2022-24750 修复）
- 📝 后续考虑升级到 8.x 获取新功能和持续安全更新

### 2.6 Supabase Swift (后端服务)

**使用情况:** 认证、数据库、实时订阅
**代码位置:** 多个服务文件中使用

**版本要求:** from: "1.0.0" -> 最新: 2.41.1

**版本跨越:** 1.x -> 2.x 有重大 API 变更

**已知漏洞:**
- 初步分析未发现公开 CVE

**建议:**

- 📝 后续计划迁移到 2.x 版本以获取最佳安全性
