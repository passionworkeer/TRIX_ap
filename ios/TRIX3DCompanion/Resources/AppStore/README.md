## Quick Start

### 1. Design App Icon
1. Read `documents/01_ICON_SPECS.md`
2. Design icon at 1024x1024 resolution
3. Export all required sizes (11 total)
4. Place in `assets/icons/`

### 2. Capture Screenshots
1. Read `documents/02_SCREENSHOT_SPECS.md`
2. Take screenshots on real devices (or simulator with Xcode watermark)
3. Capture 8 scenes per device
4. Localize for all languages
5. Place in `assets/screenshots/[language]/[device]/`

### 3. Prepare Descriptions
1. Review `documents/03_DESCRIPTIONS.md`
2. Customize descriptions if needed
3. Copy/paste to App Store Connect

### 4. Privacy Policy
1. Review `documents/04_PRIVACY_POLICY.md`
2. Host at https://trix3d.com/privacy
3. Provide translations for all languages

### 5. Submit to App Store
1. Follow `documents/05_SUBMISSION_CHECKLIST.md`
2. Complete all items before submission
3. Submit via App Store Connect

## Common Issues and Solutions

### Issue: Icon rejected for transparency
**Solution**: Ensure 1024x1024 icon has no transparency. Use solid background.

### Issue: Screenshots from simulator rejected
**Solution**: Use physical device screenshots OR simulator with Xcode watermark.

### Issue: Missing privacy policy URL
**Solution**: Host privacy policy at https://trix3d.com/privacy before submission.

### Issue: Age rating too high
**Solution**: Answer age questionnaire carefully. App should be 4+.

### Issue: Review rejected for missing permissions explanation
**Solution**: Ensure all Info.plist permission descriptions are clear and user-friendly.
