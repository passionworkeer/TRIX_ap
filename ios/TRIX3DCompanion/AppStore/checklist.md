# App Store 发布检查清单

> TRIX 3D Companion - 发布前必须完成的检查项目

---

## 1. 准备工作

- [ ] **Apple 开发者账号** - 确保拥有有效的 Apple 开发者账号
- [ ] **App Store Connect 访问** - 确保有权限访问 App Store Connect
- [ ] **Bundle ID 注册** - 在 Apple Developer Portal 注册 Bundle ID: `com.trix3d.companion`
- [ ] **App Record 创建** - 在 App Store Connect 创建 App Record
- [ ] **证书准备** - 创建和下载分发证书（Distribution Certificate）
- [ ] **Provisioning Profile** - 创建 App Store 分发描述文件
- [ ] **App Icon 资源** - 从设计师获取所有尺寸的应用图标
- [ ] **App Screenshot 资源** - 从设计师获取所有设备的截图

---

### 设计要求
- [ ] 使用 PNG 格式
- [ ] 1024x1024 无透明通道（用于 App Store）
- [ ] 其他尺寸可以有圆角效果
- [ ] 建议包含产品 logo 和应用名称
- [ ] 确保在不同背景下清晰可见
- [ ] 导出前压缩优化文件大小

3. **实时监控** - 打印进度监控界面

## 6. 审核信息

- [ ] **审核账号** - 准备测试账号供审核使用
- [ ] **审核说明** - 编写审核备注
- [ ] **联系信息** - 提供审核团队联系方式

### 测试账号

> **安全注意**: 从 v1.2.0 开始，生产构建中不再包含硬编码的测试账号。审核人员可以通过注册流程创建测试账号。

```
说明: 审核人员可通过应用内的注册流程创建测试账号
```

> **重要**: 出于安全考虑，生产应用 (Release) 不包含任何硬编码凭证。仅在调试版本 (Debug) 中可用 demo 登录功能。

## 8. 构建和上传

### Xcode 配置

- [ ] **版本号** - 设置正确的版本号 (1.0.0)
- [ ] **构建号** - 设置递增的构建号 (1)
- [ ] **目标设备** - 配置支持 iOS 15.0+
- [ ] **Signing** - 配置自动签名或手动签名
- [ ] **Scheme** - 配置 Release scheme

### 上传流程

- [ ] **Archive** - 使用 Xcode Archive
- [ ] **Validate** - 验证构建
- [ ] **Upload** - 上传到 App Store Connect
- [ ] **等待审核** - 提交审核申请

---

## 9. 上传后检查

- [ ] **App Store Connect** - 确认构建已处理

- [ ] **发布方式** - 选择手动或自动发布
- [ ] **区域可用性** - 选择发布的国家/地区
