# 摘要

> 记录用户的偏好、技术决策、协作模式等核心信息

---

## 用户偏好

### 工作方式
- 喜欢按功能组织代码，不按技术分层
- 重视代码可读性和模块化
- 偏好 TypeScript 严格模式
- 希望一次性完成功能，不遗留待办事项
- 重视文档和知识沉淀

### Git 工作流
- 用户说 "git" = 提交 + 推送（不要只提交不推送）
- 提交前检查敏感文件（.env 等）

### 沟通偏好
- 用最简单的话语描述需求，不需要指定技术细节
- 用户负责验收成果
- 减少打扰，自主完成工作

### 权限配置
- 超级权限：bypassPermissions，不需要频繁确认

---

## 技术栈

- React 19 + TypeScript + Vite 6
- Supabase（后端数据库和认证）
- Three.js（3D 角色渲染）
- Socket.io（WebSocket 实时通信）
- Framer Motion（动画）
- Leaflet（地图）
- Tailwind CSS

---

## 架构决策

### 三层布局
- 背景层：固定全屏 3D 渲染
- 内容层：可滚动页面
- 悬浮 UI 层：底部导航栏

### WebSocket 握手
- Challenge-Response 认证模式
- HMAC-SHA256 签名

### 路由
- 使用 HashRouter（适合移动端部署）

### 目录组织
- screens/：页面组件
- components/：可复用 UI
- features/：按业务领域组织
- contexts/：全局状态
- services/：业务逻辑

---

## 工作流程要求

### 必须使用的 Skills
1. brainstorming - 需求探索
2. tdd-workflow - 测试驱动开发
3. security-review - 安全审查
4. performance - 性能优化

### 流程
1. 理解需求 → 追问澄清
2. 制定计划
3. 完整实现
4. 自我测试（单元 + E2E）
5. 代码审查
6. 用户验收
7. 总结优化

### 测试要求
- 单元测试（vitest）
- 类型检查（tsc）
- E2E 测试（Playwright）
- 缺少任何一个都不算完成

---

## 安全措施

- JWT 认证 + HMAC 握手
- HTTPS + WSS
- Supabase 参数化查询
- React 自动转义 + CSP
- SameSite Cookie + Token 验证
