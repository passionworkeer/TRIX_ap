# TRIX Channel - 快速开始

## 一键启动

### Windows
```bash
start-trix-channel.bat
```

### Linux/Mac
```bash
chmod +x start-trix-channel.sh
./start-trix-channel.sh
```

## 手动启动

```bash
cd openclaw-skills/trix-channel
npm install
node index.js
```

## 在 OpenClaw 中使用

```
启动 TRIX Channel
生成 TRIX 配对码
```

## 在 App 中配对

1. 打开 TRIX App
2. 输入配对码
3. 完成配对

## 测试消息流

```bash
# 测试脚本
node test-trix-channel.js
```
